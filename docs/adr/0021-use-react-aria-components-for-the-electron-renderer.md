# Use React Aria Components for the Electron renderer

Replace the Remix 3 renderer with React and React Aria Components, styled by React Aria's vanilla CSS starter kit copied into the repository. Without a component library, hand-styled Remix controls drifted apart and every surface carried its own CSS. React Aria supplies consistent behaviour with keyboard and screen reader support, and the kit supplies a styled version of every component drawn from one set of theme variables. React Spectrum 2 was tried first and rejected: its accent is fixed to Adobe's blue, and Laneway keeps its amber. React Aria kits styled with Tailwind (shadcn's React Aria base, HeroUI, Untitled UI) were rejected to keep styling out of class strings.

Once copied, the kit's files are Laneway's own: Apache 2.0, pinned to the upstream commit they came from, with Laneway's changes listed beside them. Colours are set only in Laneway's theme, which overrides the kit's variables. Screens compose kit components, and Laneway's own components, such as dense lists, the repository panel, and the graph, use those variables rather than literal values. Electron's native theme follows the appearance setting, so the kit's colour-scheme rules apply unchanged. Icons stay Lucide (ADR-0020), drawn through a small adapter in place of `lucide-react`.

The renderer stays client-only inside Electron, behind the typed preload boundary and the unchanged strict CSP. Plain stylesheets need no runtime style injection, React Aria's press style is declared in the page stylesheet, and only the dev server gets a style nonce. Main and preload remain authoritative. Transient view and operation state lives in framework-free controllers that React views subscribe to, so it is tested without a DOM. Migrate screen by screen on a branch, with the React renderer as a separate page beside Remix for comparison, and merge once it reaches parity and Remix is removed, so master never carries both renderers; the order and progress are in [the migration plan](../react-aria-migration.md).
