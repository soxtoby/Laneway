# Share Git infrastructure without CLI parity

Repository entry and Laneway actions share in-process infrastructure for selecting and running system Git, validating action-specific prerequisites, and redacting failures. Electron main owns GUI-only open, clone, and initialization flows; the Laneway Engine exposes coarse-grained, scriptable Laneway actions rather than duplicating Git commands. The GUI caches the selected Git executable and version until its settings change, while each one-shot Engine invocation selects Git afresh. Repository facts are cached only within the action that consumes them. One application-wide Git executable override takes precedence over `PATH`.
