# Keep composable diffs reversible

Workbench uses diff representations that map back to exact Git and worktree content, and disables external diff programs and `textconv` in its primary diff views. Custom converted output can improve inspection but cannot reliably identify changes that Workbench can transfer into another commit; V1 therefore summarizes those files and leaves any future configured-diff view read-only.

Diff previews are snapshots: expanding a file reuses the displayed inventory's metadata, and reopening may reuse a bounded cached patch. Opening a preview does not wait for a full freshness check. Before a Workbench Operation uses a Change Selection, it must reread with the selection's expected version, bypass preview caches, and reject changed content instead of remapping the selection. Continuation pages use the same validation to avoid mixing snapshots. The snapshot version includes source evidence as well as the patch, so edits hidden by Git's line normalization still invalidate the selection.
