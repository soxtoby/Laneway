# Build and serve the desktop app with Bun

Bun builds and serves the desktop app instead of electron-vite and Vite, chiefly so the renderer is compiled by Bun's React Compiler (ADR-0026). `desktop/scripts/build.ts` bundles the main process as an ES module and the preload script as CommonJS, each with only Electron external, and the renderer page from `index.html` with its modules split, minified, and linked relatively for `file:`. The layout of `out/` is unchanged. A build takes about 0.3 seconds where electron-vite took about 15, and Bun now does the bundling, transpiling, compiling, testing, and engine compilation alike. The window's icons are found at run time in `desktop/resources` rather than imported as assets, and `tsconfig.json`'s paths, which Bun's bundler follows, map Tabler's catalogue files that the Vite config used to alias.

`desktop/scripts/dev.ts` replaces `electron-vite dev`. Bun's development server serves the renderer with hot module replacement and React Fast Refresh: the app shows its columns about 2 seconds after starting, and an edited component updates in place, keeping the page's state, in about 60 to 400ms. Fast Refresh needs `react-refresh` to resolve from the server's working directory, so it is a root dependency and the server runs from the repository root, which also lets it watch the shared packages. The compiler's plugin hands each compiled module back as TSX, because the server gives Fast Refresh only to modules it loads as JSX or TSX. The server delivers updates as `blob:` scripts and adds one inline script, so it serves a copy of the page whose CSP allows exactly those; the built page keeps its CSP. The main process and preload script rebuild, and Electron restarts, when their sources or Laneway's packages change.

The alternative of upgrading to Vite 8, with Oxc's React Compiler, was rejected because Bun covers the same needs with one tool, is much faster, and has its own compiler.
