# Draw icons from Tabler

Draw the application's icons, the starter kit's icons, and user-chosen Repository Icons from Tabler instead of Lucide (ADR-0020). With the renderer on React (ADR-0021), the application and the kit use `@tabler/icons-react`'s components directly instead of drawing node data through an adapter. They stay inline SVG, so the strict CSP still needs no font, stylesheet, or remote source. Tabler draws on the same 24-unit grid with the same round 2-unit stroke, and its outline set of about 5,200 icons, including brand marks, is larger than Lucide's. The kit's CSS targets Tabler's `tabler-icon-<name>` classes. Concepts Tabler doesn't draw remain Laneway's own strokes: the detached head, the diff and conflict controls, and collapse-all, which turns the chevrons of Tabler's `selector` to face each other.

The Repository Icon catalogue is Tabler's outline set, loaded lazily with its search tags from `@tabler/icons`. Its JSON files are outside that package's exports, so the Vite config and `tsconfig.json` map their names to the installed package. Saved icons are Tabler's kebab-case names. A Lucide name saved earlier keeps its picture only where Tabler uses the same name (such as `package` or `globe`). Otherwise the repository shows its initials until another icon is chosen, as it does for any unknown name, so Workspace State needs no migration.
