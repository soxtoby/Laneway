# Compile the renderer with the React Compiler

The renderer's components are compiled by Bun's React Compiler, which memoizes their values, callbacks, and elements so a parent's render stops at children whose inputs are unchanged. Hand-made callbacks and objects had made every column re-render its whole body whenever anything above it rendered. That was most of the cost when React Aria's focus-visibility state changed: a tab click whose interaction mode flipped held the renderer for about 190ms in development with a 105-file column, and about 110ms compiled. The build compiles its whole bundle with `reactCompiler`. The development server and the tests load modules one at a time, so a Bun plugin, `desktop/react-compiler.ts`, compiles each `.tsx` module the same way as it loads, caching it by its source; the tests preload it from `bunfig.toml`, so they run the renderer as it ships. Bun's compiler takes only `.jsx` and `.tsx` files, so hooks in `.ts` modules aren't compiled.

The compiler assumes a callback created during render may run there, so it compares the paths the callback reads at every render. A callback must not read through a value that may be undefined at render: `() => close(outcome!.id)` read `outcome.id` while `outcome` didn't exist and crashed the Publish dialog. Guard inside the callback instead, as `if (outcome) …` does, since reads behind a condition compare only the value itself. A sweep comparing every compiled module against Babel's compiler with `enableTreatFunctionDepsAsConditional`, which treats those reads as conditional, found no other such read; the compiled tests fail on one that renders. Rendering must also stay pure. A value that changes outside React, such as a loaded image or icon cache or the clock commit ages count from, is read through `useSyncExternalStore`; a forced re-render reading it again would keep the compiled value from the first render.

Babel's plugin was rejected. It offers `enableTreatFunctionDepsAsConditional`, which removes that hazard, but it took about 25ms a module, about 3 seconds for the renderer, and kept a second toolchain beside Bun; Bun compiles the renderer in milliseconds.
